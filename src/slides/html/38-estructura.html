Encabezado + payload: ¿ligero o rico?

Evento ligero

Menos acoplamiento; el consumidor consulta detalles (más latencia).

{

  "type": "pixpro.image.processed.v1",

  "id": "evt_9f2",

  "time": "2026-10-15T16:21:07Z",

  "data": { "imageId": "img_481" }

}

Evento rico

El consumidor procesa sin llamar de regreso; mensaje más grande.

{

  "type": "pixpro.image.processed.v1",

  "id": "evt_9f2",

  "time": "2026-10-15T16:21:07Z",

  "data": {

    "imageId": "img_481",

    "batchId": "b_77",

    "url": "https://cdn…/img_481.webp",

    "filters": ["sepia", "resize"]

  }

}
