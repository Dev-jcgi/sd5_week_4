¿Por dónde viajan los eventos?

ProtocoloPara qué sirve¿Dónde aparece en PixPro?
AMQPMensajería empresarial (RabbitMQ)API → broker → Digester
MQTTLigero, pensado para IoT y sensoresNo aplica en Fase 1
HTTP/2Conexiones persistentes y eficientesSPA → API REST, subida de lotes
gRPCSobre HTTP/2, ideal entre microserviciosOpcional: Digester → servicio de IA
WebSocketsBidireccional en tiempo realNotifier → SPA: “tu imagen está lista”

Un mismo flujo combina varios protocolos: el broker habla AMQP hacia dentro y el usuario recibe por WebSocket hacia fuera.
