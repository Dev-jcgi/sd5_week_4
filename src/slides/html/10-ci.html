Pipeline de GitLab CI

buildcompile + lint
testunit + coverage
quality gatecoverage ≥ 65%
packagedocker compose build
integrationcompose up + e2e

# .gitlab-ci.yml (fragmento ilustrativo)

stages: [build, test, quality, package, integration]

test:

script: npm test -- --coverage # o dotnet test + Coverlet

integration:

script: docker compose -f compose.ci.yml up -d --build

Compose levanta API, broker, Digester y BD como en local.

Si un job falla, el merge request queda bloqueado.
